# GitHub Profile 美化页面 — 实现计划

## Context(原理与你将得到什么)

**原理**:GitHub 会把「与你用户名同名」的仓库(即 `IAmKings/IAmKings`)的 `README.md` 自动渲染到你的个人主页顶部。所谓"美观另类"的页面 = 一份精心设计的 Markdown + 嵌入的动态图片服务(URL 即图片,自带主题参数)+ GitHub Actions 定时生成的 SVG 动画(贪吃蛇),全部零服务器、自动更新。

**环境确认**:`~/Documents/ProfilePage` 为空目录;`gh` 已登录 **IAmKings**;同名仓库**尚不存在**(将新建公开仓库)。

**已确认的默认方案**(未收到你的偏好选择,按推荐执行,均可在批准前调整):
- 风格:赛博暗黑霓虹(紫 `#7928CA` → 青 `#00D9FF` 渐变,tokyonight 主题卡片)
- 组件:打字动画 + 统计卡全家桶 + 奖杯 + 活跃图 + 贪吃蛇
- 文案:中英混合(标题英文、自我介绍中文)
- 交付:创建 `IAmKings/IAmKings` 公开仓库并推送

## 实现步骤

### 1. 个性化探测(避免占位符)
- `gh api user` 获取 name/bio/followers;`gh api users/IAmKings/repos?per_page=100&sort=pushed` 与各 repo 的 `languages_url` 汇总出真实 Top 语言 → 用于技能图标墙与文案个性化

### 2. 初始化仓库并写两个文件

**`README.md`** — 页面设计稿(自上而下):
1. **头图**:`capsule-render.vercel.app/api?...&type=waving&height=200&text=IAmKings&color=gradient(7928CA,00D9FF)` 深色波浪渐变
2. **打字动画**:`readme-typing-svg.demolab.com` 循环播放 3 句(`Full-Stack Developer` / `Building cool things with code ✨` / `Open Source Lover 💜`)
3. **About Me**:中英混排简介,3-4 条 bullet
4. **⚡ Tech Stack**:`skillicons.dev` 图标墙(按第 1 步探测的真实语言)
5. **📊 GitHub Stats**:三卡一行 —— `github-readme-stats`(stats)/ `streak-stats.demolab.com`(streak)/ `top-langs` compact,全部 `theme=tokyonight`;外层用 `<picture>` + `prefers-color-scheme` 做深浅色自适应(浅色用 default/transparent 主题)
6. **🏆 Trophies**:`github-profile-trophy.vercel.app`,`theme=tokyonight&no-frame=true&row=1&column=7`
7. **📈 Activity Graph**:`github-readme-activity-graph.vercel.app`,`theme=tokyo-night`
8. **🐍 Snake**:`<picture>` 引用 `raw.githubusercontent.com/IAmKings/IAmKings/output/github-contribution-grid-snake(-dark).svg`
9. **Footer**:shields.io 徽章行(社交链接按探测结果填)+ 渐变分隔线收尾

**`.github/workflows/snake.yml`** — 贪吃蛇生成:
```yaml
name: generate snake
on:
  schedule: [{cron: "0 0 * * *"}]   # 每日刷新
  workflow_dispatch:
  push: {branches: [main]}
permissions: {contents: write}
jobs:
  generate:
    runs-on: ubuntu-latest
    steps:
      - uses: Platane/snk/svg-action@v3
        with:
          github_user_name: ${{ github.repository_owner }}
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark
      - uses: crazy-max/ghaction-github-pages@v4
        with: {target_branch: output, build_dir: dist}
        env: {GITHUB_TOKEN: "${{ secrets.GITHUB_TOKEN }}"}
```
