## 👋 About Me · 关于我

- 🤖 **Android Craftsman** — Kotlin / Jetpack Compose，做**本地优先**的移动应用：[ZhiBox](https://github.com/IAmKings/ZhiBox)、[Dougie](https://github.com/IAmKings/Dougie)、[Sonlet](https://github.com/IAmKings/Sonlet)；自动更新能力已抽成独立库 [ReleaseKite](https://github.com/IAmKings/ReleaseKite)
- 📈 **图表 / 数据** — [LKanvas](https://github.com/IAmKings/LKanvas)：把 KLineChart 搬进 Compose Canvas（纯 Kotlin 计算，接口对齐上游）；[LaNina](https://github.com/IAmKings/LaNina)：从气候信号到市场的证据监测
- 📜 **中文排印** — 把「赫蹏」排版规则移植到 Kotlin（[kheti](https://github.com/IAmKings/kheti)），横排竖排都要美；也整理[宋词选粹](https://github.com/IAmKings/Songci-Selection)与[譯](https://github.com/IAmKings/Yi)
- 🧠 **AI & 工具链** — 在手机上跑 LLM（[llama.kt](https://github.com/IAmKings/llama.kt)）；给 Agent 做中文互联网研究（[last30days-skill-cn](https://github.com/IAmKings/last30days-skill-cn)）；把 PDF / EPUB 变成**可溯源**的 Anki 卡组（[anki_card_builder](https://github.com/IAmKings/anki_card_builder)）
- 🎮 **小玩意制造机** — [五子棋](https://github.com/IAmKings/Gobang)、[Make24](https://github.com/IAmKings/Make24)、[VoidMusic](https://github.com/IAmKings/VoidMusic)（把桌面物件变成鼓机）、[Anchor 锚点](https://github.com/IAmKings/Anchor)（微行为辅助）—— 写代码也要好玩
